# weddell-seal-mark-recap

Field data capture for Weddell seal mark–recap studies.

The Android application lives in [`weddell-seal-android/`](weddell-seal-android/). Open that directory in Android Studio, or run Gradle from there:

```bash
cd weddell-seal-android
./gradlew :app:testDebugUnitTest
```

See [`weddell-seal-android/app/src/test/resources/README_TESTING.md`](weddell-seal-android/app/src/test/resources/README_TESTING.md) for full test instructions.
